Gestiona el directorio de empleados. Sube el Head Count o agrega uno por uno.
Head Count diario

Sube el Excel de Head Count cada día. El sistema lo compara contra el directorio actual, te muestra exactamente qué va a cambiar (altas, bajas, actualizados) antes de tocar nada, y solo entonces aplica los cambios. Nunca toca cuentas de admin, chef ni empleados agregados a mano.

Arrastra el Excel de Head Count aquí o haz clic para seleccionar
ID B360, LOGIN B360, ID PLATA, LOGIN PLATA, NOMBRE COMPLETO, PUESTO, CENTRO
Revisa todo el directorio de una vez: corrige solo ID B360 duplicados donde está claro cuál copia tiene el correo correcto (borra las demás para siempre, reactiva la buena si hacía falta) — y avisa de cualquier otra cosa rara que encuentre (gafetes repetidos, correos repetidos, empleados del Head Count sin ID B360, duplicados donde no está claro cuál es el bueno) sin tocarla, para que la revises a mano. No toca a nadie que hayas desactivado tú por otra razón.
💚 Empleados subsidiados 100%

Empleados a los que la empresa les cubre toda la comida (no se les cobra nada, y sus comidas se ven aparte en Reportes y Dashboard). Sube un Excel con las mismas columnas del Head Count, o agrégalos uno por uno con la casilla "Subsidiado 100%" al agregar un empleado más abajo. Si el ID B360 ya existe en el directorio, nomás se marca como subsidiado; si no existe, se crea de cero.

Arrastra el Excel de subsidiados aquí o haz clic para seleccionar
